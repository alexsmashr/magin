# MAGÍN S.R.L. — WEB MASTER BRIEF

## 1. Función del sitio web

El sitio web de MAGÍN S.R.L. será la base institucional de su ecosistema digital.

No debe funcionar como un catálogo extenso de servicios.

Debe ayudar a un potencial cliente organizacional a:

1. Descubrir MAGÍN.
2. Comprender rápidamente qué hace.
3. Entender su enfoque integral.
4. Explorar sus capacidades.
5. Evaluar evidencia y casos.
6. Comprender cómo trabaja.
7. Encontrar información útil.
8. Iniciar una conversación.

La experiencia debe reducir incertidumbre progresivamente.

---

# 2. Público principal

Buyer Persona de referencia:

Claudia.

Responsable de proyectos corporativos o profesional que participa en:

- planificación
- coordinación
- comunicación
- innovación
- Recursos Humanos
- proyectos internos

- procesos difíciles de comprender

La homepage será una experiencia vertical continua.

## SECCIÓN 01 — HERO

Presentar inmediatamente:

- quién es MAGÍN
- qué integra
- para quién trabaja

Título:

De la idea a la implementación.

- logo frontal

# 8. Cinco capacidades MAGÍN

La identidad permite representar cinco capacidades:

M — Marketing
A — Audiovisual
G — Diseño Gráfico
I — Informática
N — New Media

Visualmente aparecerán cinco elementos.

Cada uno utilizará su color correspondiente.

## Concepto visual

Cinco cajas / maletines de herramientas contemporáneos.

Deben parecer:

- objetos corporativos
- conceptuales
- premium
- minimalistas
- tecnológicos
- tridimensionales

NO deben parecer:

- juguetes
- cofres de videojuego
- cajas militares
- maletines industriales
- elementos cyberpunk

Cada maletín se abre y permite visualizar algunos ICONOS 3D conceptuales.

Los iconos deben sobresalir parcialmente.

No llenar cada maletín de objetos.

# 23. Uso del 3D

El 3D tendrá niveles.

## Nivel 1

CSS / iluminación / profundidad sencilla.

## Nivel 2

Objetos tridimensionales específicos.

Hero MAGÍN.
Maletines.
Iconos.

## Nivel 3

Interacciones Three.js solamente cuando aporten valor.

No convertir toda la web en Canvas WebGL.

El contenido principal debe seguir siendo HTML accesible y rastreable.
