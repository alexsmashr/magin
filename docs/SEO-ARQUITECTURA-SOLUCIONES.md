## Flujo de enlazado interno recomendado

1. Artículo informacional (`/blog/[slug]`) → línea comercial (`/#tecnologia-innovacion` o futura `/soluciones/...`)
2. Línea / soluciones → evidencia (`/#portafolio`) cuando haya casos verificados
3. Evidencia o soluciones → proceso (`/#proceso`)
4. Proceso → contacto (`/#contacto`)
